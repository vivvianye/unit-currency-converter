## Комп'ютерний практикум 15
### Знайдені вразливості та їх виправлення:

- XSS: у проєкті немає innerHTML і v-html; усі дані виводяться через інтерполяцію Vue, яка екранує HTML. Вільного тексту від користувача немає (лише число та вибір зі списку).
- Перевірка: у rates.json у поле date підставлено `<img src=x onerror="alert('XSS')">`. З тимчасовим v-html спрацьовував alert, з інтерполяцією рядок відображається як текст.
- Сховища: IndexedDB (ConverterDB/history) і localStorage містять лише суму, одиниці, результат і час; чутливих даних немає.
- Секрети: ключів і паролів у коді немає; API Frankfurter ключа не потребує.
- HTTPS: для публікації обрано GitHub Pages (HTTPS за замовчуванням).
